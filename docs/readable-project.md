# 프로젝트 화면을 읽는 순서

프로젝트 화면은 목표, 현재 결과, 남은 조건과 다음 행동을 먼저 보여줍니다. 전체 계획에서는 공동 Phase와 담당 작업을 함께 보며, 특정 사람을 선택해도 다른 담당자의 책임이 사라지지 않습니다. Phase와 작업 상세에서 같은 목표에 대한 막힘·완료 조건을 확인합니다.

확인 결과는 각 작업과 단계에서 무엇을 확인했고 결과가 무엇인지 설명합니다. 검사만 통과하고 작업이나 사람 승인이 남아 있으면 그 조건을 함께 표시합니다. 내용을 설명할 기록이 없으면 미기록으로 남깁니다. 문서상 완료는 과거 기록이고 현재 검사 통과와 별개입니다.

실행 이력에서는 세션의 목표, 담당자, 실행 시각·종료 상태와 목표 확인 결과를 구분합니다. 실행이 끝났거나 횟수가 많아졌다는 사실로 목표를 달성했다고 판단하지 않습니다. 참고 자료에서는 연결된 단계와 문서의 날짜·버전·요약을 읽고 원문을 펼칩니다. API/MCP 설정은 실제 호출 관측과 구별합니다.

검사 명령, 내부 식별자, runner 영수증, 원문과 해시는 기술 확인이 필요할 때 펼치는 원본 기록에 보존합니다. 화면의 설명은 저장된 자료의 투영이며 새 모델 분석이나 새로운 검증 결과가 아닙니다.

최신 요청·명세·독립 검토·작업 결과·부모 인수 증거는 `specs/ai-pms-readable-project/`에 있습니다. 실제 Chrome 데스크톱 확인과 명령 회귀 검사는 별도로 기록합니다. 공개 합성 미리보기와 실제 문서 기반 비공개 미리보기는 분리하며 이번 화면 수정은 공개 배포를 포함하지 않습니다.

전체 계획의 구성요소와 연결 도표는 프로젝트 목표 아래 단계별 작업·담당자·상태와 연결된 API/MCP·문서를 보여줍니다. 실선은 소속, 참고 영역은 기록된 참조 관계입니다. 단계·작업 노드를 선택하면 기존 상세로 이동합니다. 단계에 연결되지 않은 참조는 프로젝트 공통으로 표시하며 실행 의존성이나 호출 성공을 추정하지 않습니다. 최신 도표의 검증 범위는 `specs/ai-pms-component-map/integration-proof.json`에 기록합니다.
