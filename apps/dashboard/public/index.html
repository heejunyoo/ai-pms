파일을 선택하기 어려운 환경에서는 정규화 스냅샷 JSON을 직접 붙여넣으세요.

공개용 가상 프로젝트와 가상 문서입니다. 실제 개인 자료, 앱 훅 관측, 모델 분석, 현재 실행 검증 또는 최종 인수의 증거가 아닙니다. 합성 실행 기록 예시 보기 → · 수집 모델 JSON · 문서 작업 제외 · 전체 가상 문서 입력 JSON

수집 모델은 현재 관측 상태만 담습니다. 문서 작업과 출처는 전체 가상 문서 입력에 있으며, 이 입력은 빌더용 자료입니다. 스냅샷 가져오기만으로 문서 작업 화면이 재현되지는 않습니다.
