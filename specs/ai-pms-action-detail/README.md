# 한 페이지에서 한 가지 판단

사람과 프로젝트를 고르는 목록, 한 프로젝트의 전체 계획, 한 작업의 행동 상세를 별도 주소로 구분합니다. 목록에 전체 차트를 쌓거나 작업 상세에 모든 Phase를 다시 나열하지 않습니다. 기존 네이티브 hash 기반 페이지 전환을 사용해 새 의존성을 추가하지 않습니다.

작업 상세는 다음 행동·실제 담당자·구체적인 사유·완료 조건을 먼저 표시하고 검사/문서/원문은 접습니다. 이유나 결정권자가 기록되어 있지 않으면 미입력으로 표시합니다. 읽기 전용 공개 예시에서 승인/결정/검사를 실행했다고 가장하지 않습니다.

공동 예시는 Alice와 Bob이 하나의 고객 지식 검색 목표와 WBS를 공유합니다. Alice의 구현·검토와 Bob의 중복 정책 합의 작업은 기존 task.owner에 선언되어 있습니다. Bob의 막힘 설명에는 Alice와 정책을 합의해야 한다는 예시 기록을 명시했습니다. 실제 다중 사용자 송신을 증명하는 예시는 아닙니다.

검사: python3 specs/ai-pms-action-detail/check_action_detail.py

실제 주소·reload·뒤로/앞으로·계획 복귀·1440/390px 표시는 부모 browser-observation.json, 최종 공개 범위는 release-proof.json에서 확인합니다. 이전 inline 상세 인수는 새 페이지 IA 인수가 아닙니다.
