## Event contract v1
One UTF-8 JSON object per line, schema_version=1, adapter_version='1', event_id UUID, observed_at UTC ISO, occurred_at nullable (never invent native event time), source codex/claude/manual, native_event string, kind session.start/session.end/prompt.observed/tool.requested/tool.completed/tool.failed/agent.start/agent.end/turn.stopped/unknown OR project.baseline/decision.recorded/artifact.recorded/check.recorded/acceptance.recorded for explicit records. authority='observed' or 'declared' (manual only). project_id local opaque stable UUID determined from normalized cwd locally, session_id and agent_id and parent_agent_id and turn_id and tool_call_id nullable strings (missing native fields remain null). tool_name nullable, links object {phase_id,task_id,decision_id,artifact_id,artifact_version,check_id} nullable strings, data object allowlisted only. missing_fields array. No raw prompts, command text, output, transcript, absolute paths or credentials in event log. Tool names/native IDs bounded and sanitized, unrecognized tool names not arbitrary payload. Native IDs must not be confused with provider model. Explicit records allow user-selected summary (max2000 chars) and scope/goal/check status/environment as specified and documented; reject likely credentials and absolute personal paths in explicit content. No automatic completion inference.
## Logger interface
python3 logger.py hook --source codex|claude reads stdin JSON, log root --log-dir optional (default ~/.local/state/harness-activity). append partition daily JSONL; owner-only dirs/files, concurrent appends with POSIX flock, validate size/types, no stdout, hook failure nonblocking exit0 but stderr concise metadata warning no payload; do not silently lose evidence. Local private project-index stores cwd->UUID and is never exported; support explicit --project-id for cross-device alias via manual command, document mapping limitation.
python3 logger.py record --kind KIND --project-id ID [--session-id ID] --data JSON [--links JSON] validates exact allowlists, exit nonzero invalid explicit records. A hook --project-id override optional useful portability. --log-dir accepted CLI. Manual decision is declared, not verified authority. Status and artifact version refer exact links, checks do not imply acceptance. Unknown native events logged kind unknown with missing markers. Default no transcript parsing/file hashing or command classification.

## Exact per-kind data allowlist (parent resolved before implementation)
Hook data={} only. project.baseline {summary,scope,goal}; decision.recorded {summary}; artifact.recorded {summary}; check.recorded {summary,status,environment}, required status pass/fail/unknown; acceptance.recorded {summary,status,environment}, required status accepted/rejected/pending. summary/scope/goal max2000 chars; environment max80. Required links: baseline phase_id; decision decision_id; artifact artifact_id+artifact_version; check check_id+artifact_id+artifact_version; acceptance artifact_id+artifact_version. Other link keys nullable. This requires declaration precision without implying observed run or acceptance.

## Final v1 baseline revision (before any release)
LINKS includes baseline_version (nullable bounded ID). project.baseline requires phase_id+baseline_version links and nonempty goal+scope data. decision.recorded requires phase_id+baseline_version+decision_id links and nonempty summary+reason data; scope_added and scope_removed optional bounded strings. Baseline revision relation is project_id+phase_id+baseline_version, never the bare version string. All other record kinds may include baseline_version. Artifact relation is project_id+artifact_id+artifact_version, never the bare version alone. Tool pairing includes provider source+project+session+agent+tool_call_id and requires nonnull call ID. These amendments supersede earlier narrower allowlists in this document.

Manual record CLI additionally accepts optional --agent-id, --parent-agent-id, --turn-id, --tool-call-id (same bounded ID validator), so declarations can explicitly link exact native runs without inferring ownership. Parent Kit temp validation uses preview/public with existing site/vercel.json copied as test input to preview/vercel.json; this is local test fixture, no infra mutation. Browser file URL open was rejected by automation security policy (only HTTP/HTTPS allowed); do not work around that rejection. Visual/file-picker verification remains unverified; offline JS parser/filter/link checks remain runnable.
