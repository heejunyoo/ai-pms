# 구현 상태 · 2026-09-30

## 완료한 범위

Handoff로 기록기, 화면, Kit 연결을 파일 경계가 겹치지 않는 3개 작업으로 나눠 구현하고 부모가 통합 검사를 실행했습니다. 계획과 패킷·결과는 이 폴더에 있습니다.

- 공통 기록기: `.claude/harness/activity/logger.py`. 일별 JSONL, 버전·프로젝트·세션·Agent·턴·호출 ID, 누락 필드, 로컬 동시 쓰기와 개인정보 허용 목록.
- 명시 기록: 목표와 범위 기준 버전, 결정 이유와 추가·제외 범위, 결과물 버전, 검사 환경·상태, 별도 수락 상태. 수동 Agent 연결도 선언으로 표시합니다.
- 화면: `viewer.html`. 여러 파일 가져오기, 프로젝트·출처 필터, 결정/실행 구별, 정확한 결과물·기준 버전 연결, 미관찰 근거, 오류·중복·충돌 표시. 최근 250개와 연결 근거 10개만 화면에 표시하며 한도를 알립니다.
- Kit: 정본 생성기에 패키지를 포함하고 Codex·Claude 한국어/영어 설치 안내에 기존 안전 훅과 병합하는 기록 명령을 추가했습니다. 로컬 `implementation.zip`과 안내 페이지를 다시 생성했습니다.

## 무엇을 운영에 쓸 수 있나요

첫 용도는 범위 변경 검토와 결과 인수 근거 찾기입니다. 실행 시간순 기록은 어떤 호출이 관찰됐는지 보여줍니다. 명시 기록은 어떤 범위 기준에서 무엇을 바꾸기로 했는지, 어느 결과물 버전을 검증했는지 보여줍니다. 연결되지 않은 항목은 재확인 대상으로 남깁니다.

자동 훅은 판단 이유를 확보하지 못합니다. 따라서 결정 이유는 별도 기록이 필요합니다. Phase나 진행률을 토큰·파일 수로 계산하지 않습니다. 검사 통과와 사용자 수락은 별도입니다. 프롬프트·명령·출력 본문과 전체 MCP 도구명은 기본 로그에서 제외하므로 의미 검색과 자동 결과물 귀속에는 한계가 있습니다.

## 검증

- 부모 재실행: 기록기 통합 검사 10개 통과. 동시 24개 기록, 공급자 tool_use_id 정규화, 개인정보·잘못된 입력·실패 처리 포함.
- 화면: JS 문법과 실제 가져오기 함수의 형식·필터·중복·연결 검사 통과.
- `verify_flow.py`: 실제 CLI로 만든 명시 기록 5개와 합성 훅 입력 3개를 화면의 실제 가져오기 함수가 8개 모두 읽음. 합성 입력은 앱 훅 전달 증거가 아닙니다.
- Kit 정본·임시 빌드: 34페이지 검사 통과. 언어 구조, 기존 URL, HTML/JS, 개인정보, 오프라인 리소스, ZIP, 기존 헤더 검사 포함.
- `python3 ~/.codex/harness/verify.py` 통과.

브라우저 자동 승인 검토가 file:// 열기를 거부했습니다(HTTP/HTTPS만 허용). 우회하지 않았고 실제 파일 선택·화면 표시·모바일 렌더는 미확인입니다. `activity-integration-result.json`에 통합 상태를 partial로 남겼습니다. 설치된 Codex·Claude 앱의 실제 훅 전달도 미확인입니다.

## 다음 구현 순서

1. 실제 프로젝트 한 곳에 Kit 기록 훅을 병합하고 새 세션에서 신뢰·전달·지연·누락을 확인합니다. 현재 사용자의 전역 설정은 변경하지 않았습니다.
2. 같은 범위 변경 사례를 기존 자료와 이 화면으로 각각 검토해, 결정 이유와 결과 버전 찾기에 걸리는 시간·틀린 귀속을 비교합니다.
3. 중앙 가져오기는 검증된 JSONL 계약을 소비하도록 만듭니다. 전송 대상·동의·보존·재시도·인증 설계를 확정한 다음 진행합니다. DB·외부 API·배포 변경은 현재 환경 지침상 별도 승인이 필요합니다.

현재 구현은 로컬 수집·명시 기록·오프라인 조회입니다. 중앙 자동 동기화, 문서 의미 추출, Agent에 현재 기준 재주입, WBS/Gantt/스토리보드 생성은 후속 범위입니다. 온라인 Kit 배포는 실행하지 않았습니다.

## 실무자 피드백 후 화면 수정

로그 카드 나열에서 프로젝트 검토 흐름으로 수정했습니다. 첫 화면은 목표·범위, 변경 이유, 결과물별 확인할 일과 검사·판단 상태를 보여줍니다. 원본 ID와 이벤트는 상세 보기로 내렸습니다. 결과물 검토에서 판단·이유를 작성하면 declared acceptance JSONL로 내려받아 다시 가져올 수 있습니다. 검토 요약 텍스트도 다음 작업에 전달할 수 있습니다. 실제 결과물 본문, Agent 자동 작업 전송, 사용자 인증은 이번 화면의 범위가 아닙니다. 검사 미기록·실패, 버전이 다른 검사, 수락 기록 왕복을 추가 검사했습니다.
