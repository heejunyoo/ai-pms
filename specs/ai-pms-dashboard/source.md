# 이번 구현의 사용자 원문

> 내가 다시 설명할텐데, 하나의 사용자의 다수 세션을 넘어서, 다수 사용자의 다수 세션을 보고자 하는게 목적이야.

> 각각의 사람들이 각각이 어떤 목적을 가지고 무엇을 만들고자 하는지, 그 단계에서 어떤 문서들을 만들고 어떻게 진행이 되는지, 완성 상태에 도달은 했는지 등등을 보고자 하는거고

> 완성의 기준이 테스트 통과라는 것도 알수 있고 로깅 할 수 있을거라고 생각한다는 거야.

> 자동수집 부분은 이후 고민해도 될 문제인것 같아. 각자의 PC 가 어디에 위치해 있는지 알 수 없잖아. 훅에서 internal webhook API 를 연결할 수 있는것도 아니고 지금 상황에서. 나머지를 구현하고, 대시보드까지 완성하자.

이 원문은 PRODUCT-INTENT.md와 PRODUCT-CLARIFICATION.md를 보충합니다. 이번 완료 범위는 오프라인 입력 기반의 중앙 프로젝트 현황/상세 대시보드입니다. 자동 수집·원격 배포·새 API/DB는 제외합니다.
