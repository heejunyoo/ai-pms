# 전체 계획과 현재 위치

첫 화면에서 사람을 선택하면 프로젝트 목표와 모든 Phase가 연결됩니다. 완료 단계 수, 먼저 확인할 단계, 남은 단계와 마지막 프로젝트 완료 확인을 봅니다. Phase를 클릭하면 해당 그래프 바로 아래에서 책임 작업과 완료 조건·막힘·다음 행동·검사 근거를 확인합니다.

Phase 전체 상태는 현재 검증 계산의 결과이며 개인 작업 수로 다시 계산하지 않습니다. 모든 Phase 완료와 최종 프로젝트 완료는 별도입니다. Phase 순서는 선언 계획이며 의존성이 확정된 일정이 아닙니다. 계획 날짜/기간 계약이 없어 Gantt 납기를 추정하지 않습니다. 세션·MCP·원본 기록은 펼쳐 보는 근거입니다.

검사: `python3 specs/ai-pms-phase-flow/check_flow.py`. 실제 브라우저/390px 확인은 DOM 시뮬레이션과 구분합니다. 최신 배포/확인 범위는 release-proof.json을 따릅니다.
