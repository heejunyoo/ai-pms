# 토스 원칙을 반영한 AI PMS 정보 구조

토스의 공개 Product Principles를 PMS에 맞게 적용했습니다. 토스 공식 제품/제휴나 TDS 컴포넌트 설치를 뜻하지 않습니다.

| 관리자의 질문 | 화면 |
|---|---|
| 누구의 프로젝트를 보고 있는가? | 첫 화면의 사람 범위 선택 |
| 내가 지금 판단할 일은 무엇인가? | 판단이 필요한 작업 목록과 작업 확인 |
| 무엇을 만들며 어디까지 왔는가? | 목표와 책임 작업 n/N를 보여주는 프로젝트 목록 |
| 어느 단계의 어떤 작업인가? | 작업 현황의 단계별 담당 작업 |
| 왜 이런 상태인가? | 완료 조건, 검증·문서·승인 근거 펼침 |
| 어떤 환경·도구·데이터를 쓰는가? | 상세의 연결·세션 기록 더보기 |

JSON 가져오기/내보내기와 고급 필터는 펼침에 있습니다. 필수 기능을 없애지 않고 필요할 때 찾도록 배치합니다. 공동 프로젝트의 전체 진행과 선택한 사람의 책임 작업은 구분합니다. 검사 통과·사람 승인·사업 성과는 서로 다릅니다.

출처: [토스 Product Principles](https://toss.im/tossfeed/article/tossproductprinciples), [토스 UX Writing](https://toss.im/tossfeed/article/uxwriter-interview).

검증 명령: `python3 specs/ai-pms-toss-ia/check_ia.py`. 실제 브라우저 검증 결과는 별도 릴리스 기록을 확인하세요.
