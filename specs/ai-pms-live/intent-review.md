# 독립 목적·설계 검토

판정: **aligned**. 사람 → 세션 → 목표 인수/근거 → 회사·팀 북극성과 실제 증분 중앙 전달을 구현 범위로 유지합니다. 모델/API 계약을 이관할 수 있습니다.

검토 중 발견한 수집 건강의 중앙 전달, 출처 admission, 프로젝트 등록 전 훅 보존, 목표/기여 확인의 digest 결합, 종료 우선순위, 보수적인 지표 판정, 삭제 미지원의 명시적 상태가 반영됐습니다. 마지막으로 session의 `source_project_id`가 추가되어 같은 사람·환경·도구·세션 ID라도 native 프로젝트 UUID에 따라 정확히 구분됩니다.

현재 원문/명세 SHA-256은 동반 JSON에 기록했습니다. `verify_live.py`는 네 구현 검사를 실행하도록 연결되어 있습니다. 이 목적 검토에서 구현 검사를 통과했다고 주장하지 않습니다.

구현 검토에서 확인할 핵심 반례:

- 종료했으나 실패한 세션, 종료하지 않았으나 검증된 세션, 목표가 없는 세션을 구분합니다.
- 동일 ID/버전에서 목표나 작업 정의 변경, 지연 도착/동시 시각/미래 이벤트, native UUID가 다른 동일 세션 ID를 구분합니다.
- 다른 사람의 기록·검토를 변경하는 project 교체와 인증 주체를 사칭한 수락/기여 확정을 거부합니다.
- 로그 기록 실패, 건강파일 실패, 전송 중단, ACK 분실과 재시작, project보다 먼저 온 훅, 지원하지 않는 삭제를 정상 완료로 표시하지 않습니다.
- 실제 HTTP 수신에서 투영과 화면 반영까지 검증하고 원격 두 환경/실제 앱 훅 증거와 합성 loopback 결과를 구분합니다.

공식 훅 계약 확인: [Codex Hooks](https://learn.chatgpt.com/docs/hooks), [Claude Code Hooks](https://code.claude.com/docs/en/hooks). 실제 앱 설치·trust·호출은 이번 설계 검토에서 검증하지 않았습니다.

본 검토는 설계 승인입니다. 실제 앱 훅, 운영 목적지, 비공개 로그 전달, 실제 브라우저 및 원격 다중 사용자 운영이 확인됐다는 의미가 아닙니다. 명세와 제품 구현은 수정하지 않았습니다.
