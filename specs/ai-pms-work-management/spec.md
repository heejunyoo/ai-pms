## Frozen additive contract (management.work optional in v3)

`work` exact fields: plan_id, plan_version, at, tasks, phase_gates, updates, reviews.
plan_id/version references management.plans; at UTC. Current work is the current declared plan; prior plan metadata remains in plans. Replacing it changes its identity and invalidates old reviews; this is declared planning, never automatic goal inference.

Task exact fields: id,title,phase_id,owner,required,depends_on,requirement_ids,done_when,criterion_ids,document_ids,review_required. id stable within this plan; phase references project phases; owner actor in source_refs OR null (assignment missing); required/review_required bool; title nonempty; done_when nonempty array of nonempty text; dependency IDs within work, unique, no self/cycles; requirements reference management.requirements; documents reference project.documents ids (association, not automatic acceptance). criterion_ids unique, may be empty (acceptance missing); each criterion must scope=task,target_id=task.id. Every task-scope criterion when work exists must reference a task, but not all must be required by it (show missing acceptance explicitly). Arrays bounded using existing privacy validators; duplicate/ref errors rejected.
Phase gate exact fields: phase_id,criterion_ids. Unique phase_ids; criteria scope=phase,target_id=phase. Missing/empty gate prevents phase completion, shown clearly. Taskless phase is unobserved, not complete.
Update exact fields: id,task_id,at,state,summary,next_action. state=not_started|in_progress|blocked; summary/next_action nonempty. This is a declaration, not verification. Latest observed update (at<=now); conflicting equal timestamp states => unknown, no progress inferred. Future work plan yields no complete tasks/phases/project.
Review exact fields: id,task_id,at,reviewer,decision,summary,artifact_sha256,task_sha256. reviewer actor in sources; decision=approved|changes_requested; summary nonempty; SHA256. `task_sha256`=digest({plan_id,plan_version,at,task,criteria,test_plans}) with canonical sorted compact ASCII JSON. criteria are the current definitions for task.criterion_ids sorted by id; test_plans are the latest definitions for those criteria sorted by criterion_id (same exact-time ambiguities already rejected by management). Bind full testplan records including definition, version, reason, test_files, not only IDs. Public helper work.task_digest(project,task) computes this identity. Require review.at>=work.at and review.at>=each applicable latest testplan.at. Latest observed review must match current task digest and current artifact digest; stale review cannot approve. Same-time conflicting review => pending. Review is recorded human approval (declared), not authenticated identity or business-outcome proof.
